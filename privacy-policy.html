Privacy Policy for Userscripts For All

Last updated: August 31, 2026

Overview

Userscripts For All is a Chrome extension that allows users to manage and run userscripts on web pages. This policy explains what data is collected and how it is used.

Data We Collect

We do not collect, transmit, or share any personal data with third parties. All data is stored locally on your device using chrome.storage.local and never leaves your machine except as described below.

Data Stored Locally

The following data is stored on your device only:

  • Installed userscripts and their source code
  • Your GitHub Personal Access Token
  • Script enable/disable preferences

GitHub Communication

If you choose to connect a GitHub repository, the extension will communicate with GitHub's servers (raw.githubusercontent.com) solely to fetch and sync userscripts. Your GitHub Personal Access Token is stored locally on your device and is only ever sent to GitHub's servers to authenticate these requests. It is never sent anywhere else.

Script Injection

This extension injects userscripts into web pages as directed by each script's @match rules. The extension itself does not monitor, record, or transmit any data from pages you visit.

Third Party Services

The only third party service this extension communicates with is GitHub (github.com / raw.githubusercontent.com), and only when a GitHub repository has been configured by the user.

Changes to This Policy

Any changes to this privacy policy will be reflected on this page with an updated date.
